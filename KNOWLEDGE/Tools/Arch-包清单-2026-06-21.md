## 12. 观察与数据点

1. **混合 DE**：KDE Plasma Wayland 上混了大量 GNOME 工具（cheese / eog / geary / seahorse / games / terminal），跨 DE 套件混用，但能用。
2. **AOSP / Android 重度用户**：完整 SDK + Studio + 平台版 + 投屏，是日常工作主线之一。
3. **游戏 + 折腾硬件派**：Steam + PPSSPP + Mangohud + Razer 驱动 + 双厂 GPU 驱动 + 多种电源工具。
4. **干净的包生态**：0 flatpak / 0 snap，纯 pacman + AUR；显式 / 总包比 7.6×，依赖树健康。
5. **完整的远程 / 虚拟化栈**：KVM + libvirt + OVMF + RDP，远程桌面（xrdp）和 KVM 直通都已就位。
6. **AOSP 路线明确**：包组 `kf6` + `qt6` 都齐了，`xorg` 包组 + Wayland plasma 共存，过渡态合理。
7. **空 .git 目录**：`~/ai-study/.git/` 是空目录，不是真的 git repo。知识库当前没走版本控制（如果需要可 `git init`）。

## 13. 维护建议（可选）

- `pacman -Qdtq` 看孤儿包，清理后可瘦身
- `pacman -Qeq | wc -l` vs `pacman -Qq | wc -l` 比例长期监控（>10× 提示脏）
- 定期 `reflector` 更新镜像源
- AUR 升级建议只用 yay 或 paru 之一，避免锁文件冲突
