## 关键知识点

- 禁用 Docker 自启可以显著缩短开机关键路径，但不等价于解决温度问题。
- `iso-pool` 删除后，开机日志中的 libvirt storage pool 告警消失。
- NVIDIA 处于 P8 / 低功耗不代表完全挂起；只要有图形上下文，设备可能保持 D0 active。
- KDE Wayland 下某些图形进程可能同时持有 dGPU 上下文。
- AMD iGPU `gpu_busy_percent` 高且 PPT 高时，应优先分析显示刷新率、桌面合成、窗口动画、代理 UI 或 Electron/Flutter 类应用。
