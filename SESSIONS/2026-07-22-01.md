## 问题

检查当前 OpenCode / Codex 加载的 skill 和 plugin。

---

## 分析

本次检查没有把“目录中存在”直接等同于“已经加载”，而是依次核对 CLI 版本、解析配置、自动发现目录、插件安装清单和模型可见提示。

最终结果：

- OpenCode `1.18.4`：运行时可见 1 个内置 skill `customize-opencode`；外部 plugin 为 0。
- Codex CLI `0.144.4`：运行时可见 9 个 skill，其中 5 个系统 skill、4 个用户 skill；已安装 plugin 为 0。
- Codex 配置了 `openai-api-curated` marketplace，但 marketplace 快照不是已安装插件。
- OpenCode CLI 没有枚举可命名的内置插件，因此结论只覆盖可验证的外部插件状态。

---

## 关键知识点

- Skill/plugin 状态要区分已下载、已配置、已发现和已加载。
- `opencode debug skill` 是 OpenCode skill 运行时清单的主要依据。
- `codex plugin list --json` 的 `installed` 字段才代表已安装插件。
- `codex debug prompt-input` 可以验证模型可见 skill，但原始输出可能包含完整系统上下文，不应公开。
- `~/.codex/skills` 不属于 OpenCode 默认扫描路径，两套工具的 skill 不会自动互通。
