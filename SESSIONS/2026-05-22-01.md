## 问题

在本机搭建 FreshRSS。

---

## 分析

本机已安装 Docker 与 Docker Compose，但 Docker daemon 当前未运行，`/var/run/docker.sock` 不存在，因此容器暂时无法启动。

已创建 `tools/freshrss/compose.yml`，使用 `freshrss/freshrss:latest` 镜像，将 Web 服务映射到本机 `8080` 端口，并把 FreshRSS 数据持久化到 `tools/freshrss/data/`。

---

## 关键知识点

- Docker CLI 可用不代表 Docker daemon 正在运行。
- `failed to connect to the docker API at unix:///var/run/docker.sock` 通常表示 daemon 未启动或当前环境无法访问 socket。
- FreshRSS 小规模本机部署可直接使用 SQLite，减少数据库服务维护成本。

---

## 我的薄弱点

- 需要区分 Docker 客户端、Docker daemon、Docker socket 三者的关系。
- 遇到容器启动失败时，应先看错误信息定位是镜像、配置、权限还是 daemon 问题。
